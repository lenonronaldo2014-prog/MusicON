# Demos MusicON Lab

Aurora, Órbita e Maré violeta são pequenos loops instrumentais sintetizados especificamente para este protótipo. Foram gerados matematicamente com senos, envelopes e percussão sintética; não usam gravações, samples ou músicas comerciais. Podem ser usados e alterados como parte deste projeto.

Formato: WAV PCM mono, 16 bits, 22.050 Hz. São demonstrações curtas do player, não um catálogo musical.
